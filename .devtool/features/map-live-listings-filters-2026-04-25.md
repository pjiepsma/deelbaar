# Map live listings + basic filters

Implement the MVP discovery base on the map.

## Scope
- Show live listings on the map (public discovery).
- Support marker selection and quick preview behavior.
- Add basic filters for category and radius/distance.

## Acceptance criteria
- Live listings render on first map load.
- Filters update visible map results.
- Marker tap leads to listing preview and/or detail path.
- Draft listings are excluded from public map results.
