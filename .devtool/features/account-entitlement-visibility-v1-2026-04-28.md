# Account entitlement visibility (v1)

Expose entitlement/access scope clearly in account settings.

## Scope
- Display current scope access level (city/province/country/world).
- Show status and optional expiry.
- Add contextual CTA hooks for scope upgrades.

## Acceptance criteria
- User can view current entitlement scope and state.
- Expired/revoked states are rendered correctly.
- Entitlement source and expiry are visible when present.
- Data shown matches backend entitlement records.
