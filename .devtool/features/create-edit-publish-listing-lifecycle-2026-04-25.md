# Create/edit/publish listing lifecycle

Build the owner listing lifecycle with draft/live states.

## Scope
- Create listing form with required MVP fields.
- Edit flow for existing owner listings.
- Publish state transitions: draft -> live.

## Acceptance criteria
- Owner can create a listing in draft.
- Owner can publish to live and unpublish back to draft.
- Public map only includes live listings.
- Lifecycle state is visible and understandable in owner UI.
