# Account profile management (v1)

Enable users to manage core identity and address/profile fields safely.

## Scope
- Edit profile fields: name, surname, avatar.
- Edit address and home-area preferences.
- Persist and expose profile data needed by account and owner flows.

## Acceptance criteria
- User can update profile fields and see updates reflected immediately.
- Validation errors are clear and actionable.
- Address and home-area changes persist without breaking related flows.
- User cannot edit another user's profile data.
